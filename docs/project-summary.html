Visual Pet —— 基于 Electron 的 Windows 桌面宠物

一款会坐在桌面角落、散步、说话、提醒你的小宠物。透明无边框、置顶常驻，集「陪伴 + 实用工具 + AI 对话」于一体。项目完全自包含：便携 Node、免安装、不写注册表，删除文件夹即卸载。

主要功能

  • 桌面形象与互动：Canvas 程序化 Q 版宠物（橘猫 / 黑猫 / 白猫 / 蓝耳兔 / 绿蛙 / 蕾米埃尔 6 款装扮）+ 图片形象模式；支持拖拽、单击说话、自动散步、久置打盹
  • 实用工具：待办提醒（到点气泡 + 系统通知）、番茄钟、整点报时、置顶显示
  • 语言与陪伴：多场景台词库（分时段问候 / 鼓励 / 健康提醒 / 卖萌…）、打字对话、语音朗读（TTS 拟人化：音色优选 / 文本预处理 / 分段节奏 / 逐段高亮）
  • 智能对话（云端大模型）：流式逐字输出、多轮记忆 + 长会话摘要压缩、工具调用（建待办 / 开番茄钟 / 查知识 / 报时）、对话中自动记忆、联网搜索、三层知识（长期记忆 / 个人资料库 / 网络）
  • 上下文感知：状态注入（待办 / 番茄钟 / 时间）、主动找话题（上下文开场 + 冷场关心）、上下文状态条、情绪驱动表情（气泡变色 + 桌宠情绪徽标）
  • 隐私与性能：API Key 加密存储（系统 safeStorage）、内存约 260MB、空闲 CPU≈0、云端失败自动回退本地规则

模块组成

层级文件 / 模块职责
主进程main.js窗口管理、托盘、原生菜单、全部 IPC 通道
search.jsBing 联网搜索（抓取解析，无需 key）
knowledge.js长期记忆 / 个人资料库 / 对话日志的持久化与关键词检索
渲染层pet桌宠本体：绘制、动画、散步、拖拽、气泡、提醒
panel面板：待办 / 番茄钟 / 设置 / 知识库管理 / AI 配置
chatAI 对话窗口：流式、多轮、工具、情绪、主动找话题
lines台词库（多套语音：默认 / 蕾米埃尔）与去重选择
character程序化绘制 6 款角色（含蕾米埃尔专属形象）
settings-shared共享默认配置、服务商预设（智谱 / DeepSeek / 通义 / Kimi）
数据localStorage共享设置（三窗口实时同步）
knowledge\memory.json（记忆）、chat-log.json（对话日志）、资料文档（txt/md）

技术亮点

  • 便携零侵入：便携 Node 随项目走，不动系统、即删即卸
  • 质量保障：隔离分区冒烟测试（真实 IPC 模拟）+ 多代理对抗式代码审验，累计修复数十个真实缺陷
  • 性能优化：主循环按状态降帧率（活动 60 / 空闲 15 / 打盹 6 fps），空闲 CPU 趋近于 0
  • 全面中文适配：中文语音（晓晓等神经音色）、Bing 中文搜索、国内大模型一键接入
