虚拟桌宠 · 使用说明

简要版 · 绿色版免安装

启动

  • 双击 桌宠-便携版.exe（单文件，免安装）
  • 或双击桌面「桌宠」快捷方式

基本操作

  • 左键拖住桌宠 = 移动它
  • 左键单击 = 它说句话
  • 右键 = 菜单：打开面板 / 说句话 / 对话 / 整点报时 / 置顶 / 退出
  • 长时间不理它 = 打盹睡觉，点一下叫醒

面板（右键 → 打开面板）

  • 待办：添加任务，可设提醒时间，到点桌宠提醒你
  • 番茄钟：设工作时长，开始后桌宠显示倒计时
  • 知识库：教它记住事情（如「我喜欢喝冰美式」）、查看/删除记忆
  • 设置：形象（卡通/图片）、皮肤、大小、散步、说话频率、语音朗读、云端 AI

对话（右键 → 对话）

  • 打开聊天窗口，打字回车发送，回复逐字流式显示
  • 云端 AI：在设置里填 API Key（智谱 GLM 免费 / DeepSeek / 通义 / Kimi）；没填 Key 或断网时自动用本地规则回答
  • 提问会自动联网搜索，答案更准
  • 教它记东西：说「记住：……」或到面板知识库页
  • 语音朗读：设置里开启后，回复会用系统语音读出来

常见问题

  • 云端报 401 = API Key 无效，去服务商平台重新生成
  • 首次运行被杀毒提示 = 未签名程序，点「更多信息 → 仍要运行」
  • 数据存本机（记忆/聊天记录/设置），卸载即清

卸载

  • 删除 exe（及 %APPDATA%\桌宠 数据目录）即可，无残留
