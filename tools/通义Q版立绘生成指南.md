# 通义万相生成 Q 版立绘指南

> 目标：从一张**原图**生成**与它相似**的 Q 版萌系立绘，作为桌宠默认形象。
> 桌宠侧我已经改好，只等这张图；生成后把图片路径告诉我即可，我会自动抠图、裁切并接入桌宠。

---

## 推荐方法：图片风格转换（保真度最高，无需写描述）

1. 打开**通义万相**（官网 tongyi.aliyun.com/wanxiang，或「通义」App → 万相）。
2. 进入「**图像生成**」→「**图片风格转换**」。
3. 上传你的原图（玩偶 / 虚拟形象 / 照片都行）。
4. 风格模板选「**Q版卡通**」，把「卡通强度」调到 **80~95**（越低越像原图，越高越 Q）。
5. 点击生成，会返回 **3 张**不同构图的结果，挑一张表情、姿态最好的。
6. **背景要求（重要）**：尽量让背景是**纯色或浅色**（如白/米白/浅灰）。这样我的脚本能自动抠成透明底。
   - 如果背景复杂，可先在通义用「**一键抠图**」导出透明 PNG 再给我（更好）。
7. 生成时选**最高清晰度档**；尺寸不用太挑（正方形或接近竖版都行）。

> 这个方法把整张图"卡通化"，不依赖你描述主体，所以对**玩偶/虚构角色**这类说不清的对象最稳。

---

## 备选方法：文生图 + 参考图（风格转换不理想时）

- 「文生图」模式 → 上传原图到「参考图」，勾选「保持主体相似性/特征保持」。
- 参考提示词模板（按需改配色/发型描述）：

```
Q版三头身卡通角色，全身，正面站立，大眼睛，圆润可爱，大头小身体，
柔和厚涂阴影，保留原图主体的配色与核心特征，干净纯色浅色背景，高清细节
```

---

## 进阶可选：图生组图（一次性多姿态）

通义万相（Wan2.7 模型）支持「**图生组图**」，可一次生成多张同风格系列图。
如果你想以后给桌宠加"多姿态"，可以用它多出几张不同动作的同款 Q 版，之后都能接入。
