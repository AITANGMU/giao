# 虚拟桌宠 🐱

一个会坐在你桌面角落、散步、说话、提醒你的 Electron 小宠物。完全自包含，不写系统注册表，删除整个文件夹即卸载。

## 快速开始

1. **双击 `启动桌宠.bat`**（无控制台窗口），或 **`启动桌宠(调试).bat`**（带日志，方便排查）。
2. 桌宠出现在屏幕右下角，可以随意拖拽，单击它会说话，右键弹出菜单。
3. 托盘图标在系统通知区域，可以随时找回/退出。

> 若启动失败，用 **`启动桌宠(调试).bat`** 运行，把黑窗口里的报错发给我。

## 功能

| 功能 | 怎么用 |
| --- | --- |
| 散步 | 默认关闭；面板 → 设置勾选「散步」后会在桌面自动走动，也可以直接拖到任意位置 |
| 说话气泡 | 单击/空闲/拖拽/被叫醒/完成待办/番茄钟结束时都会说话。右键菜单「对话」打开独立聊天窗口，可完整查看对话记录。每套装扮可绑定专属语气（蕾米埃尔 = 神秘/戏谑/优雅） |
| 云端 AI 对话 | 面板 → 设置 → 云端 AI 对话：填 API Key 后，打字对话走大模型（智谱 GLM 免费 / DeepSeek / 通义 / Kimi / 自定义）；没配 Key 或断网时自动回退本地规则。Key 只存本机，聊天内容会发给服务商 |
| 联网搜索 | 提问含"什么/怎么/最新/天气/新闻…"或"查一下"时，自动搜索 Bing 并把结果注入回答（需云端 AI 已启用） |
| 记忆 / 知识库 | 对话里说「记住：我是程序员」让它长期记住（面板「知识库」页可管理）；资料放 `knowledge\` 文件夹（txt/md），提问时按关键词检索引用 |
| 语音朗读 / 持久化 | 设置里开「语音朗读回复」，桌宠用系统语音读出回复；聊天记录重启后自动恢复；API Key 用系统加密存储（safeStorage），不再明文 |
| 待办提醒 | 右键 → 打开面板 → 待办：添加任务并设置时间，到点气泡+系统通知 |
| 番茄钟 | 面板 → 番茄钟：设工作时长，桌宠右下角显示倒计时，阶段结束提醒 |
| 整点报时 | 面板设置或右键菜单勾选「整点报时」，整点会报时 |
| 换皮肤 | 面板 → 设置：可切换「卡通角色 / 图片」两种形象；图片形象可点「更换图片…」选任意本地图；卡通角色有 6 种预设皮肤（含「蕾米埃尔」，选她台词也会自动换成她的语气） |
| 打盹 | 长时间不碰它，它会闭上眼睛睡觉，点一下就叫醒 |

## 快捷键 / 操作

- 左键按住拖拽 = 移动桌宠
- 左键单击 = 说话
- 右键 = 菜单（打开面板 / 说句话 / 对话 / 整点报时 / 置顶 / 退出）
- 「对话」打开独立聊天窗口：回车或点「发送」发送，上方为完整对话记录

## 技术说明

- 便携版 Node 位于 `node-portable\`，仅本项目使用，不影响系统。
- 默认形象是 `assets\pet-image.png`（透明背景，可直接替换该文件换形象）；也可在面板「更换图片…」里选任意本地图片；卡通角色用 Canvas 程序化绘制。声音用 Web Audio 生成，无音频文件。
- 数据存在 Chrome localStorage（`pet.settings`），卸载即清空。

## 重新安装依赖

如果 `node_modules` 丢失，用 PowerShell 在项目目录执行：

```powershell
$env:ELECTRON_MIRROR = "https://npmmirror.com/mirrors/electron/"
.\node-portable\npm.cmd install --registry=https://registry.npmmirror.com
```
